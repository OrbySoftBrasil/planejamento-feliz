# Planejamento Feliz

Crie um protótipo funcional, somente frontend, de uma aplicação web SaaS para professores da Educação Infantil, da creche até o final da pré-escola.

O produto funciona como um assistente de planejamento pedagógico. Ele ajuda o professor a organizar o planejamento anual, mensal e semanal, preparar atividades, acompanhar datas e projetos escolares e reduzir o trabalho realizado fora da escola.

A experiência precisa ser extremamente simples, didática e acolhedora, pensada para professores com pouca familiaridade com tecnologia. Evite excesso de menus, informações, configurações e termos técnicos. O sistema deve funcionar muito bem no computador e principalmente no celular.

O protótipo deve permitir visualizar estes fluxos principais:

- Tela inicial mostrando o dia atual, a semana, próximas atividades, pendências e datas importantes.

- Planejamento anual, mensal e semanal conectados entre si.

- Calendário pedagógico com projetos, eventos e datas comemorativas.

- Biblioteca organizada de atividades já criadas.

- Busca e sugestão de atividades semelhantes antes de criar algo novo.

- Criação e adaptação de atividades conforme faixa etária, turma, materiais disponíveis, duração e preferências do professor.

- Assistente em formato de conversa, capaz de ajudar a planejar, alterar atividades e salvar o resultado no sistema.

- Perfil pedagógico do professor e contexto da turma.

- Registro simples de como uma atividade funcionou, para melhorar sugestões futuras.

- Visualização e impressão de uma atividade pronta.

Use dados fictícios realistas para uma professora da pré-escola, com uma turma de crianças de 4 anos.

Crie um exemplo em que existe uma atividade próxima relacionada ao Dia da Água. A professora percebe que ainda não preparou a atividade, conversa com o assistente, recebe uma sugestão, faz uma pequena adaptação e salva no planejamento semanal.

A aplicação não deve parecer apenas um chatbot. O chat é um recurso dentro de um sistema visual de planejamento e organização.

Use um estilo moderno, leve, organizado e profissional, com aparência amigável para Educação Infantil, mas sem ficar infantilizado. Priorize cards, calendário visual, textos curtos, ícones claros, bom espaçamento e baixa carga cognitiva.

Não crie backend, autenticação real ou integrações externas. Use dados mockados e faça os principais fluxos navegáveis e interativos para demonstrar como o produto funcionaria.

Não crie uma landing page comercial. Comece diretamente pela aplicação já autenticada.
